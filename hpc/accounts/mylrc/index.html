    Using the MyLRC Portal¶

    MyLRC is the web portal for managing Lawrencium user accounts and projects. Use it to request an account, join or request a project, manage project members, and check SU usage and jobs.

    For an overview of the service and the project types, see the MyLRC service page.

    Create your MyLRC account¶

    Everyone who uses Lawrencium, including PIs who may only manage projects, needs a MyLRC account.

    1. Go to https://mylrc.lbl.gov and sign in through CILogon with your institution's identity.
    2. Follow the on-screen instructions to register.
    3. On the Welcome page, click Review and sign the cluster User Access Agreement.

    Existing cluster users

    If you already had a Lawrencium account before using MyLRC, you still need to sign the User Access Agreement the first time you log in to the portal.

    Get a Lawrencium user account¶

    You get a Lawrencium user account by joining a project. You do not request the user account separately.

    • If you do not have a user account yet, one is created when a PI or project manager approves your request to join a project.
    • If you already have a user account, the new project is added to it.

    When your new account is ready, you receive a confirmation email with instructions for logging in.

    Before your first login¶

    Wait for the confirmation email

    It can take a few days between joining your first project and receiving the confirmation email. Do not set up your one-time password or try to log in to the cluster before the email arrives. Doing so can cause authentication failures.

    Once the email arrives, follow Logging in and Multi-Factor Authentication. All cluster access uses one-time passwords (OTPs).

    Join a project¶

    Check with the project's PI before you ask to join.

    1. Log in to MyLRC.
    2. Click Join and select the project.
    3. Wait for approval. The PI or a project manager must approve every request; requests are never approved automatically. MyLRC sends email reminders to you and to the project managers.

    You can check the status of your request on the Requests page.

    Request a new project¶

    A PI, or someone the PI asks, can request a PCA, Condo or Recharge project.

    1. Log in to MyLRC.
    2. Click Create.
    3. Choose the type of computing allowance from the drop-down menu.
    4. Follow the on-screen instructions to finish the request.

    For what each project type offers, see Project Accounts.

    Manage a project¶

    PIs and project managers manage projects from the project page. Go to My LRC Cluster Projects and click the project ID.

    Task How
    Approve join requests Click Review Join Requests
    Add a user Click Add Users. The user must already have a MyLRC account.
    Remove a user Click Remove Users
    Make someone a project manager In the Users list, click the blue person-and-pen icon in the Actions column
    Update the project name or description Edit it on the project page
    Monitor SU usage In the Allocations field, click the folder icon under More details

    Users can remove themselves from a project with Leave Project.

    Archive Project

    Archive Project expires all allocations on the project. Everyone in the group loses access to the resources in those allocations. Be sure before you click it.

    Check usage and jobs¶

    • Allocations and SU usage: shown on each project page.
    • Jobs: click Jobs in the menu bar. Use the filter to find a job, then click its job ID for details.

    Users see only their own jobs. PIs and project managers can see all members' jobs and SU usage.

    Change your email address¶

    This is useful if you are leaving your organization and will keep using the cluster with a different email address.

    1. Click your username in the top right corner, then User Profile.
    2. Click Manage Emails and add the new address.
    3. Verify the new address. You can then make it your primary email.

    Track your requests¶

    The Requests page, in the menu bar, lists all your requests and their status. PIs and project managers also see requests for their projects.

    Close a user account¶

    Removing a user from a project does not close their account

    Removing a user in MyLRC, or using Leave Project, does not close the user account. The $25/month account fee continues as long as the account and its home directory exist. See Charges and Billing.

    To close an account:

    1. Copy any software, files or data that others depend on out of the user's home directory.
    2. The PI, the project's main contact or the account holder submits a user account closure request on Freshservice, including what should happen to the user's files.

    Accounts are not closed automatically when someone leaves the Lab.

    Change a project's PID or delete a project¶

    These requests cannot be made in MyLRC.

    • Change the PID billed for a project or account: submit a PID change request on Freshservice.
    • Delete a project: email scienceithelp@lbl.gov.

    Questions¶

    Email scienceithelp@lbl.gov with questions about accounts or projects.
